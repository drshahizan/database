# 📊 Database Project Proposal  

This project involves the preparation of a **Database Project Proposal (Phase 1)** for the course **Database (SECP2523)**. The objective of this phase is to analyse an organization’s current data management practices and to propose an appropriate database-based solution that addresses existing problems and supports organizational operations effectively.

The project begins with a **problem background study**, which includes an analysis of the organizational context and how data is currently stored, managed, and utilized. This study provides a clear understanding of the existing system and highlights issues related to data handling, information flow, and operational efficiency.

Based on the background study, a **problem statement** is formulated to clearly describe the weaknesses and limitations of the current system. These problems form the basis for proposing suitable solutions that can be addressed through a database application.

The project then outlines the **proposed solutions**, focusing on how a database system can improve data organization, reduce redundancy, enhance data integrity, and support efficient data retrieval. A brief feasibility consideration is included to ensure that the proposed solution is practical and achievable.

Clear **project objectives** are defined to specify the goals of the proposed database system. These objectives guide the design and development of the system and ensure alignment with organizational needs. The **scope of the project** is also clearly stated, identifying what will be included and excluded to avoid ambiguity.

In addition, the project defines the **system boundaries**, including the boundaries of the database application and the identification of major **user views**. This ensures that different user roles and their interactions with the database are properly considered.

A **project plan** is included to describe how the system will be developed. This plan outlines the estimated development timeline, responsible personnel, expected completion date, and supporting planning tools such as the **Work Breakdown Structure (WBS)** and **Gantt Chart**.

Finally, the proposal includes a **requirement analysis** based on the current (AS-IS) system. This analysis documents existing or proposed business rules, data requirements, and transaction requirements, including data entry, data update or deletion, and data queries. These requirements serve as the foundation for the next phase of the project, which focuses on database conceptual design.

Overall, this Project Proposal phase establishes a structured and comprehensive foundation for the development of a database system, ensuring that subsequent design and implementation phases are based on clearly defined requirements and realistic planning.
