## 🧭 Project Overview

This project focuses on the design and development of a database system to support an organization’s operational and information management needs. The primary aim is to analyse existing (as-is) business processes and data handling practices, identify current problems and limitations, and propose an improved database solution that is systematic, efficient, and scalable.

The proposed database system will act as a centralized repository for storing, managing, and retrieving organizational data. It is intended to address common issues such as data redundancy, data inconsistency, limited accessibility, and inefficient manual or semi-computerized processes.

Through requirement analysis, the project will identify user views, business rules, data requirements, and transaction requirements. These elements will later be translated into a structured database conceptual design using Entity Relationship Diagrams (ERD) and Enhanced ERD (EERD).

This proposal phase lays the groundwork for the complete database development lifecycle, ensuring that all subsequent designs and implementations are aligned with real organizational needs and academic standards.
